# Requirement matrix — Admin Web + supporting BE (handoff)

Ma trận ánh xạ yêu cầu ↔ contract ↔ code ↔ test source ↔ trạng thái.
Cập nhật sau mỗi đợt (F0..F6). Mọi "đã triển khai" tức là source đã đọc và kiểm tra tĩnh;
"chưa kiểm chứng" nghĩa là chưa chạy build/test/runtime.

HEAD tham chiếu (working trees rất nhiều thay đổi chưa commit):
- Web `76766f8e2f37474ab3467307ba0cf9af71c74d6a`
- BE `12b9bcab53d24aceb70e7934a406c51a0658f21d`

Các file source có thay đổi dở đã thấy nhiều hơn HEAD — chỉ ghi những file trong working tree,
không quy toàn bộ dirty diff là do đợt này viết.

## Trạng thái tổng quát

- F0 — sửa lỗi rà soát draft hiện có: ongoing.
- F1 — Auth/session/MFA: code dở nhiều, cần vá concurrency + cookie/native + challenge.
- F2 — Finance thủ công: code gần đủ, cần state machine UI + tranh chấp + idempotency retry.
- F3 — PT certificates: code đã có storage check prefix, cần owner check + audit atomic.
- F4 — Booking review: BOOKINGREVIEW.TSX RỖNG — phải tạo nội dung + nối UI.
- F5 — Support/audit/overview: AuditTrail + Reports đã có; settings/MFA cần đối chiếu.
- F6 — Đồng bộ contract + bàn giao.
