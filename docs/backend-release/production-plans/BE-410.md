# BE-410 — Email provider
Plan revision1; external delivery BLOCKED OPS-02. Depends BE-802 contract; local adapter làm độc lập.
## Scope
In: verification/reset/security/support templates, provider delivery, retries/bounce handling khi provider hỗ trợ.
Out: marketing campaigns, gửi email thật không được phép, log nội dung link token.
## Contract/data
Email request qua outbox; templateId/version/recipient/message correlation. Token link ngắn hạn, allowlisted frontend base URL, không redirect theo Host header chưa trust.
SMTP/provider creds secret store; external provider sandbox/domain SPF/DKIM/DMARC operator thực hiện.
## Steps
1. Map IEmail abstraction hiện có/needed và Identity token lifecycle; snapshot template locale với minimal data.
2. Local MailHog verify links, neutral API response forgot/resend; no delivered claim chỉ vì queued.
3. Adapter timeout/retry bounded; không nuốt lỗi hoặc resend storm; delivery status nếu provider có feedback.
4. Staging actual delivery tới test inbox authorized; bounce/config failure alert.
## Tests
Expired/reset-used link, poisoned URL, SMTP down→outbox retry, duplicate event dedup, rejected recipient, rate limit/resend, no sensitive logs.
Retry SMTP có thể gây duplicate mail nếu provider nhận rồi mất ack; không claim exactly-once, token single-use bảo vệ side effect.
## Client impact
MOB-800 verify/reset deep links; WEB-800 reset + MFA không bypass; support pending UI.
## Recovery
Pause dispatch when bad config, giữ queued expiry; resend mới tạo token/version phù hợp thay vì gửi token hết hạn. Không lùi account verified state.
