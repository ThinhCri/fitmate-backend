# BE-400 — VNPay adapter thật
Plan revision1, baseline PROD-2026-09-22-v1. External integration BLOCKED OPS-03; source implementation vẫn làm được sau BE-808.
## Scope
In: checkout URL, callback validation, transaction query/refund adapter, sandbox evidence.
Out: multi-provider, bypass chữ ký, live merchant activation, tự thu/hoàn tiền thật.
## Contract/data
Giữ IPaymentProvider use cases đã chốt BE-808/809. Trước code đọc tài liệu merchant chính thức được cấp: version, query encoding, canonical signature, amount scaling, timezone, HTTP method, IPN acknowledgment codes.
Không mặc định POST trong spec cũ là phương thức VNPay yêu cầu. Nếu spec sai, BE-801 sửa server endpoint và docs, không bắt provider đổi protocol.
Lưu merchant reference/attempt/provider transaction IDs unique; raw payload hạn chế retention/access, không echo ra FE.
## Steps
1. Inventory current stub/callback endpoints/config; version test fixtures từ tài liệu merchant, không lấy snippet blog làm chuẩn.
2. Implement signer/verifier constant-time comparison, exact canonical encoding/amount conversion, merchant/order/currency checks.
3. Persist checkout intent trước network; idempotent provider attempt; query timeout ambiguity trước tạo intent mới.
4. IPN verified→transactional settlement→outbox; duplicate/out-of-order stable ack theo provider; return chỉ hint.
5. Implement query/refund interface cho BE-809, mapping retriable vs terminal errors.
6. Sandbox end-to-end với OPS-03; live cấu hình riêng chỉ operator approved.
## Tests
Tampered amount/signature/merchant, wrong booking, duplicate txn, invalid encoding, callback late after expiry, query unknown/timeout, provider success before worker crash, refund request duplicated.
Fixture unit tests không thay sandbox evidence. Không gửi arbitrary success ack cho invalid request.
## Client impact
MOB-802 checkout deep-link/poll; WEB-802/803 trạng thái provider vs booking tách riêng.
## Recovery
Disable checkout nếu config/signature mismatch; giữ reconciliation/read. Provider side money không rollback bằng DB restore; query/reconcile và compensating entries.
