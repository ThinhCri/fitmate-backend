## Scope
- **In**:
  - **Support Tickets**:
    - Lifecycle: `Open`, `InProgress`, `WaitingForUser`, `Resolved`, `Closed`.
    - User APIs (`SupportTicketsController`): Tạo ticket (`POST /api/v1/support/tickets`), danh sách ticket cá nhân (`GET /api/v1/support/tickets`), xem chi tiết có bảo vệ IDOR trả về 404 (`GET /api/v1/support/tickets/{id}`), gửi phản hồi (`POST /api/v1/support/tickets/{id}/reply`), tự đóng ticket (`POST /api/v1/support/tickets/{id}/close`).
    - Admin APIs (`AdminSupportTicketsController`): Danh sách ticket hệ thống có lọc phân trang (`GET /api/v1/admin/support/tickets`), xem chi tiết (`GET /api/v1/admin/support/tickets/{id}`), phản hồi người dùng (`POST /api/v1/admin/support/tickets/{id}/reply`), đổi trạng thái (`POST /api/v1/admin/support/tickets/{id}/status`).
  - **User Preferences**:
    - Lưu trữ tùy chọn cá nhân và quyền đồng ý (`UserPreference`): ngôn ngữ (`Language`), giao diện (`Theme`), múi giờ (`Timezone`), thông báo (`NotificationsEnabled`, `EmailNotifications`, `PushNotifications`), đồng ý chia sẻ dữ liệu sức khỏe (`HealthDataSharingConsent`), đăng nhập sinh trắc học (`BiometricLoginEnabled`).
    - API (`UserPreferencesController`): `GET /api/v1/users/me/preferences`, `PUT /api/v1/users/me/preferences` đảm bảo không mất cấu hình qua các lần đăng nhập lại.
  - **Public System Capabilities & Contact Info**:
    - Endpoint công khai (`SystemCapabilitiesController` - `GET /api/v1/system/capabilities`):
      - Phản ánh trung thực trạng thái AI: `ai_enabled: false` (theo chỉ đạo mới từ tài liệu cập nhật `ai-contract.md` và `BE-817 revision 2`), không fake inference, không che giấu lỗi.
      - Phản ánh các module cốt lõi (manual workout, meal logging, booking, payment, chat) hoạt động độc lập bình thường.
      - Cung cấp hằng số chính sách nền tảng (`platform_fee_bps: 1000`, `min_cancel_hours: 24`, `refund_window_days: 7`).
      - Cung cấp thông tin liên hệ và URL chính sách công khai (`support_email`, `hotline`, `terms_url`, `privacy_url`, `deletion_policy_url`).
      - Tuyệt đối không để lộ hạ tầng, connection strings hoặc secret keys.
  - **Unit Tests**:
    - `SupportServiceTests`: 11 test cases kiểm thử toàn diện tạo ticket, IDOR 404, phản hồi, đóng ticket, chuyển đổi trạng thái và phân trang.
    - `UserPreferenceServiceTests`: 2 test cases kiểm thử tạo mặc định và cập nhật lưu giữ qua các phiên.
