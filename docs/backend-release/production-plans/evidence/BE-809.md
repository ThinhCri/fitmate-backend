## Scope
- **In**:
  - Triển khai luồng hoàn tiền (`POST /api/v1/admin/finance/refunds`):
    - Kiểm tra quyền Admin (`_authz.EnsureRoleAsync(adminId, "Admin", ct)`).
    - Kiểm tra lý do hợp lệ (tối thiểu 5 ký tự).
    - Kiểm tra số tiền hoàn hợp lệ (`AmountVnd > 0`).
    - Bảo vệ Invariant: Số tiền hoàn tích lũy không vượt quá tổng tiền thanh toán (`payment.RefundedSoFarVnd + requestedAmount <= payment.AmountVnd`).
    - Cập nhật trạng thái `Payment`: `PartialRefunded` nếu hoàn một phần, `Refunded` nếu hoàn toàn bộ (đồng thời cập nhật `Appointment.Status = Refunded`).
    - Tạo bản ghi `Refund` và enqueue Outbox event `finance.refund_processed`.
  - Triển khai đối soát thanh toán và hoàn tiền (`GET /api/v1/admin/finance/reconciliation`):
    - Tổng hợp số liệu giao dịch thanh toán thành công, tổng tiền đã thu, tổng số lượt hoàn tiền, tổng tiền đã hoàn, và phát hiện bất đồng bộ số liệu (`Discrepancies`).
  - Mở rộng bộ unit tests toàn diện trong `tests/Fitmate.UnitTests/AdminFinanceServiceTests.cs`.
- **Out**:
  - Giao diện Admin portal Web (thuộc WEB-803).
  - Tự động gọi API hoàn tiền sang cổng thanh toán đối tác bên ngoài (thuộc BE-400 VNPay Adapter).
