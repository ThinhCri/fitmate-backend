## Commands kiểm chứng cho Kỹ sư / Tester

1. **Biên dịch mã nguồn**:
   ```powershell
   dotnet build Fitmate.slnx
   ```
2. **Kiểm tra công cụ nạp dữ liệu UAT an toàn (Seeder)**:
   - Thử nghiệm trợ giúp:
     ```powershell
     dotnet run --project src/Fitmate.Api -- seed-uat-data --help
     ```
   - Thử nghiệm chốt chặn bảo mật (Kỳ vọng từ chối khi DB không thuộc whitelist):
     ```powershell
     $env:DB_NAME = "fitmate_production"
     dotnet run --project src/Fitmate.Api -- seed-uat-data --allow-uat-seed
     ```
   - Chạy nạp dữ liệu trên database UAT được phép:
     ```powershell
     $env:DB_NAME = "fitmate_uat"
     $env:UAT_SEED_PASSWORD = "UatStrongPassword123!"
     dotnet run --project src/Fitmate.Api -- seed-uat-data --allow-uat-seed
     ```
   - Chạy lại lần 2 để kiểm chứng tính lũy kế (Idempotency - không reset mật khẩu hay đè tiến độ):
     ```powershell
     dotnet run --project src/Fitmate.Api -- seed-uat-data --allow-uat-seed
     ```
3. **Thực thi bộ test tích hợp API 10 hành trình trên PostgreSQL thật**:
   ```powershell
   dotnet test tests/Fitmate.IntegrationTests --filter "FullyQualifiedName~UatJourneysIntegrationTests"
   ```
