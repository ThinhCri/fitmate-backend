## Behavior & Code Changes
- **Admin MFA (`AdminMfaController.cs`)**:
  - `POST /api/v1/admin/auth/mfa/setup`: Cấp TOTP shared key và chuẩn hóa `authenticator_uri` (`otpauth://totp/...`).
  - `POST /api/v1/admin/auth/mfa/verify`: Xác thực mã TOTP với Identity AuthenticatorTokenProvider, bật 2FA (`SetTwoFactorEnabledAsync`) và sinh 10 recovery codes.
  - `POST /api/v1/admin/auth/mfa/disable`: Xác thực mã TOTP hoặc mật khẩu Admin để tắt 2FA.
- **Last-Admin Protection (`AdminUserService.cs` & `EfAdminUserStore.cs`)**:
  - `IAdminUserStore.CountActiveAdminsAsync`: Đếm số lượng Admin đang hoạt động (không bị khóa và chưa bị xóa).
  - `AdminUserService.SetLockAsync`: Từ chối khóa Admin nếu `activeAdmins <= 1` với mã lỗi `FITMATE.IDENTITY.CANNOT_LOCK_LAST_ADMIN`.
- **Web Cookie Auth (`AuthController.cs`)**:
  - Tự động gắn HttpOnly cookie trên `POST /api/v1/auth/login` và `POST /api/v1/auth/refresh`.
  - Tự động xóa cookie trên `POST /api/v1/auth/logout`.
