## Hiện trạng và Mục tiêu
- **Mục tiêu**: Hoàn thiện toàn bộ hạ tầng container hóa và luồng CI/CD tự động bằng chứng cứ thực nghiệm theo yêu cầu sản xuất (P0, BR-16):
  1. Triệt tiêu toàn bộ cảnh báo build (`NU1603`) do sai lệch phiên bản package `Microsoft.Extensions.Hosting.Abstractions`.
  2. Đảm bảo cấu hình Docker Compose độc lập (`compose.yml`), không bị đè bởi các file ghi đè môi trường phát triển (`compose.override.yml`), hỗ trợ đầy đủ các biến cấu hình cổng và volume.
  3. Tích hợp kiểm thử tích hợp (Integration Tests) chạy trên dịch vụ PostgreSQL thực tế trong luồng GitHub Actions CI (`.github/workflows/ci.yml`).
  4. Tự động hóa kiểm tra bí mật (Gitleaks), kiểm thử đơn vị, kiểm chứng hợp đồng OpenAPI (Spectral), build và cache Docker images (API + Migration bundle), kiểm thử khói container hóa (Smoke test), và chuẩn bị deployment gate cho Staging/Production.

## Scope
- **In**:
  - `src/Fitmate.Infrastructure/Fitmate.Infrastructure.csproj`: Sửa phiên bản `Microsoft.Extensions.Hosting.Abstractions` về `8.0.1` (khớp chính xác với dependency của `Microsoft.AspNetCore.DataProtection 8.0.10`), triệt tiêu hoàn toàn cảnh báo `NU1603` và lỗi `NU1605`.
  - `compose.yml`: Bổ sung cấu hình cổng chuẩn hóa `"${API_PORT:-8080}:8080"` và chỉ định tường minh image tags `fitmate-api:local` và `fitmate-migrate:local`.
  - `.github/workflows/ci.yml`:
    - Bổ sung job `integration-test`: Sử dụng service container `postgres:16-alpine`, chạy bộ kiểm thử `Fitmate.IntegrationTests` và xuất kết quả TRX.
    - Cập nhật job `smoke`: Sử dụng tường minh `-f compose.yml` trong mọi lệnh Docker Compose để cô lập với môi trường local dev.
    - Bổ sung job `staging-deploy`: Khai báo môi trường `staging`, kiểm tra điều kiện nhánh và ghi nhận commit SHA / Run ID.
- **Out**:
  - Không tự deploy lên hạ tầng production trả phí.
  - Không nhúng secrets vào Docker layers.
