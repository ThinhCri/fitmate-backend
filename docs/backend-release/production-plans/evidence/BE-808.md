## Scope
- **In**:
  - Gating Provider: Chỉ cho phép sử dụng `StubPaymentProvider` trong môi trường Development / Testing hoặc khi được cấu hình rõ ràng (`Payment:AllowMockProvider = true`).
  - Trong môi trường Production khi chưa có cấu hình VNPay thực tế, hệ thống đăng ký `MissingPaymentProvider` fail-closed (throw HTTP 503 `FITMATE.PAYMENT.PROVIDER_UNAVAILABLE`), tuyệt đối không tự động giải quyết stub provider trả về thanh toán thành công giả.
  - Sửa logic khởi tạo thanh toán (`PaymentService.CreateAsync`):
    - Khởi tạo `Payment` ở trạng thái `PaymentStatus.Pending` với `RedirectUrl` từ provider.
    - Không tự ý gọi `MarkPaid(...)` khi mới chỉ sinh URL chuyển hướng thanh toán.
    - Kiểm tra số tiền thanh toán hợp lệ (`PriceListedVnd > 0`), ném `ValidationException` (`FITMATE.PAYMENT.INVALID_AMOUNT`) nếu không hợp lệ.
  - Bảo vệ Callback / Return / IPN:
    - Kiểm tra chữ ký an toàn (`VnpSecureHash`), từ chối (`RspCode = "97"`, `unverified`) nếu thiếu hoặc sai chữ ký, không xác nhận thanh toán giả.
  - Bộ unit tests toàn diện trong `tests/Fitmate.UnitTests/PaymentServiceTests.cs`.
- **Out**:
  - Sandbox credentials và adapter kết nối thực tế tới VNPay (thuộc BE-400 / OPS-03).
  - Đối soát và hoàn tiền tự động (thuộc BE-809).

## Behavior & Code Changes
- **Configuration & Provider (`PaymentOptions.cs`, `MissingPaymentProvider.cs`)**:
  - `PaymentOptions` hỗ trợ section `Payment` với `AllowMockProvider`.
  - `MissingPaymentProvider` triển khai `IPaymentProvider` throw `DomainException(FITMATE.PAYMENT.PROVIDER_UNAVAILABLE, 503)`.
- **Service (`PaymentService.cs`)**:
  - Sửa `CreateAsync` giữ trạng thái `Pending`, loại bỏ việc tự động `MarkPaid`.
  - Bổ sung kiểm tra số tiền > 0.
  - Xác thực chữ ký `VnpSecureHash` trong `HandleVnpayReturn` và `HandleVnpayIpn`.
- **API Wiring (`Program.cs`)**:
  - Gating `IPaymentProvider` dựa theo `Environment.IsDevelopment()` và `PaymentOptions.AllowMockProvider`.
- **Unit Tests (`PaymentServiceTests.cs`)**:
  - Cập nhật test `CreateAsync` assert trạng thái `Pending`.
  - Bổ sung test `MissingPaymentProvider` throw 503.
  - Bổ sung test `PriceListedVnd <= 0` throw ValidationException.
  - Bổ sung test chữ ký cho return và IPN.
