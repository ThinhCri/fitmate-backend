## Scope
- **In**:
  - Triển khai endpoints password recovery (`POST /api/v1/auth/password/forgot`, `POST /api/v1/auth/password/reset`).
  - Triển khai endpoint đổi mật khẩu authenticated (`POST /api/v1/auth/password/change`).
  - Hoàn thiện logout (`POST /api/v1/auth/logout`) hỗ trợ revoke refresh token cụ thể hoặc toàn bộ session của user.
  - Refresh Token Replay / Reuse Detection: khi phát hiện cố gắng rotate một token đã bị revoke trước đó, tự động thu hồi toàn bộ token của user (`RevokeAllForUserAsync`).
  - Password Reset Invalidation: thu hồi toàn bộ session/refresh tokens khi reset password thành công.
  - FluentValidation cho `ForgotPasswordRequest`, `ResetPasswordRequest`, `ChangePasswordRequest`.
  - Neutral response cho Forgot Password để chống email enumeration attack.
  - Unit tests cho validators và refresh token reuse detection.
- **Out**:
  - Không triển khai Admin MFA TOTP trong task này (thuộc BE-803).

## Behavior & Code Changes
- **Contracts (`AuthContracts.cs`)**:
  - `ForgotPasswordRequest(string Email)`
  - `ResetPasswordRequest(string Token, string NewPassword, string? Email)`
  - `ChangePasswordRequest(string CurrentPassword, string NewPassword)`
  - `LogoutRequest(string? RefreshToken)`
  - `PasswordResetPayload(Guid UserId, string Email, string Token, string FullName)`
- **Validators (`AuthValidators.cs`)**:
  - `ForgotPasswordRequestValidator`: bắt buộc email hợp lệ, độ dài tối đa 254.
  - `ResetPasswordRequestValidator`: bắt buộc token và new_password tối thiểu 8 ký tự.
  - `ChangePasswordRequestValidator`: bắt buộc current_password và new_password khác nhau.
- **Application (`RefreshTokenService.cs`)**:
  - `RotateAsync`: Khi `existing.RevokedAt is not null` (replay), kích hoạt `RevokeAllForUserAsync(existing.UserId)` và trả về `null`.
  - `RevokeAllForUserAsync`: Thu hồi tất cả refresh token active của user.
- **API (`AuthController.cs`)**:
  - `POST /api/v1/auth/password/forgot`: trả về `202 Accepted` trung lập, gửi outbox event `auth.password_reset_requested`.
  - `POST /api/v1/auth/password/reset`: xác thực token với ASP.NET Identity, đổi mật khẩu và thu hồi toàn bộ refresh token cũ của user.
  - `POST /api/v1/auth/password/change`: xác thực mật khẩu hiện tại và đổi mật khẩu mới.
  - `POST /api/v1/auth/logout`: thu hồi token theo body hoặc thu hồi toàn bộ session.
