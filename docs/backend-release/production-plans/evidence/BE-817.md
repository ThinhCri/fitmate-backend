  - `AiNutritionStubAdapter`: Xác thực `imageStream` (không rỗng), `contentType` (chỉ nhận jpeg/png/webp), kiểm tra `CancellationToken`, ném `AiUnavailableException` (503).

  - `AiTestFixtures`: Dữ liệu mẫu (golden fixtures) và test doubles phục vụ kiểm thử đơn vị độc lập.
  - `AiAdapterTests`: Bộ kiểm thử đơn vị cho toàn bộ các kịch bản disabled (503), cancellation, input validation và capabilities mapping.
