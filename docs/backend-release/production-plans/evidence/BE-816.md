## Scope
- **In**:
  - Bảo vệ xác thực file upload và chống giả mạo định dạng (Magic byte / MIME signature validation):
    - Kiểm tra chữ ký byte thực tế của luồng nhị phân (JPEG `FF D8 FF`, PNG `89 50 4E 47...`, WEBP `RIFF...WEBP`) để ngăn chặn các cuộc tấn công tải lên file độc hại giả danh ảnh (polyglot / disguised MIME type).
  - Quản lý định danh lưu trữ không đoán được (Unguessable storage keys):
    - Đặt tên file theo cấu trúc `{category}/{sanitized_filename}_{guid:N}{ext}`, làm sạch ký tự nguy hiểm (`FilenameSanitizer`), chống tấn công dò quét hay ghi đè.
  - Bảo vệ đường dẫn và chống Path Traversal:
    - Kiểm tra `Path.GetFullPath` trong `LocalStorageService` đảm bảo đường dẫn tuyệt đối không bao giờ vượt ra ngoài thư mục `BasePath`.
  - Cơ chế tạo và xác thực Signed URL an toàn (HMAC-SHA256):
    - Ký kết HMAC-SHA256 trên nội dung `{relativePath}\n{unix_ts}`.
    - Giới hạn thời gian sống (TTL) tối đa `SignedUrlTtlMinutes` (15 phút).
    - So sánh chữ ký an toàn với thời gian hằng số `CryptographicOperations.FixedTimeEquals` chống tấn công đo thời gian (timing attacks).
    - Ngăn chặn việc tái sử dụng chữ ký của resource này cho resource khác (cross-resource signature tampering).
  - Phục vụ file tĩnh có kiểm soát (`SignedUrlMiddleware`): Chặn toàn bộ các request trực tiếp vào `/uploads/...` thiếu chữ ký hoặc đã hết hạn với mã lỗi 403 Forbidden.
  - Ghi nhật ký định danh người tải lên (`userId`) phục vụ giám sát và kiểm tra an ninh.
  - Mở rộng bộ unit tests toàn diện trong `LocalStorageServiceTests.cs` và `HmacSignedUrlServiceTests.cs`.
- **Out**:
  - Tích hợp Cloud Object Storage trực tiếp (S3/GCS) khi chưa có yêu cầu về topology/budget (hiện sử dụng durable local abstraction).
  - Xử lý nén video/audio dung lượng lớn (chỉ hỗ trợ ảnh theo đặc tả).

## Behavior & Code Changes
- **API (`Fitmate.Api.Storage`)**:
  - `UploadsController.cs`:
    - Tích hợp hàm `ValidateMagicBytes` kiểm tra header nhị phân của các định dạng JPEG, PNG, WEBP.
    - Chuẩn hóa category về chữ thường (`request.Category.ToLowerInvariant()`).
    - Ghi log định danh người dùng `userId` tải file lên hệ thống.
  - `SignedUrlMiddleware.cs`: Chặn truy cập trực tiếp file tĩnh không có chữ ký hợp lệ hoặc đã hết hạn (403 Forbidden).
- **Infrastructure (`Fitmate.Infrastructure.Storage`)**:
  - `LocalStorageService.cs`: Đảm bảo ghi file nguyên tử (`atomic rename` từ `.tmp`), chống path traversal.
  - `HmacSignedUrlService.cs`: Ký và xác thực URL có hạn giờ dùng HMAC-SHA256 với secret key tối thiểu 32 ký tự.
- **Unit Tests (`Fitmate.UnitTests`)**:
  - `LocalStorageServiceTests.cs`: Kiểm tra ghi file nguyên tử, tạo thư mục tự động, chặn path traversal.
  - `HmacSignedUrlServiceTests.cs`: Kiểm tra round-trip URL, hết hạn, giả mạo chữ ký, chặn dùng chữ ký chéo giữa các file, chặn sai khóa bí mật và kẹp trần TTL.

## Migration / Recovery

  - Client lưu `storageKey` vào entity (như avatar/certificate/post), và sử dụng `signedUrl` có hạn để hiển thị ảnh trực tiếp.
