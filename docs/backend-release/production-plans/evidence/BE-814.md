## Scope
- **In**:
  - Triển khai endpoint đọc danh sách bình luận bài viết (`GET /api/v1/social/posts/{id}/comments`) kèm phân trang cursor và kiểm tra quyền xem bài viết/block isolation.
  - Triển khai endpoint đọc danh sách yêu cầu kết bạn chờ xử lý (`GET /api/v1/social/friends/requests?type=incoming|outgoing|all`) kèm thông tin người gửi/nhận.
  - Thực thi cách ly quan hệ chặn (`Block Isolation`) chặt chẽ ở cả 2 chiều:
    - Ẩn bài viết trong feed và post detail (`GetPostAsync`) khi có quan hệ block.
    - Chặn bình luận (`AddCommentAsync`) và thả cảm xúc (`ToggleReactionAsync`) đối với bài viết của người dùng bị block hoặc người dùng đã block mình (`FITMATE.SOCIAL.RECIPIENT_BLOCKED`).
  - Kiểm chứng Chat Friend:
    - Đảm bảo trật tự tin nhắn và cơ chế đánh dấu đã đọc tiến dần (`Monotonic Read Marker` - không lùi timestamp/read marker giữa nhiều thiết bị).
    - Idempotency dựa trên `client_message_id` cho cùng payload và trả lỗi `409 FITMATE.CHAT.IDEMPOTENCY_MISMATCH` khi khác payload.
    - Duy trì lịch sử chat an toàn sau khi hủy kết bạn hoặc block (chỉ chặn gửi tin mới).
  - Bổ sung bộ unit tests toàn diện trong `SocialServiceTests.cs`, `FriendServiceTests.cs`, và `ChatServiceTests.cs`.
- **Out**:
  - WebSocket / Real-time Gateway (thuộc phase mở rộng).
  - AI chat / AI moderation tự động ban (thuộc BE-817 / Moderation).

## Behavior & Code Changes
- **Application (`Social`, `Friends`, `Chat`)**:
  - `ISocialStore.cs`, `EfSocialStore.cs`: bổ sung `ListCommentsAsync` và lọc người dùng bị block trong feed `ListPostsAsync`.
  - `ISocialService.cs`, `SocialService.cs`: inject `IBlockStore`, bổ sung `ListCommentsAsync`, áp dụng block isolation cho post detail, comments và reactions.
  - `IFriendStore.cs`, `EfFriendStore.cs`: bổ sung `ListPendingRequestsAsync`.
  - `IFriendService.cs`, `FriendService.cs`: bổ sung DTO `FriendRequestDetailedView` và phương thức `ListPendingRequestsAsync`.
  - `ChatController.cs`: chuẩn hóa mã lỗi xác thực 403 `FITMATE.IDENTITY.NOT_AUTHENTICATED`.
- **API (`SocialController.cs`, `FriendsController.cs`)**:
  - Expose `GET /api/v1/social/posts/{id:guid}/comments`.
  - Expose `GET /api/v1/social/friends/requests`.
- **Unit Tests**:
  - Cập nhật test fakes và bổ sung 5+ test cases mới trong `SocialServiceTests.cs` và `FriendServiceTests.cs`.
