# Historical implementation plans

Plan production mới ở [production-plans](../production-plans/README.md). Thư mục hiện tại giữ plan scope cũ; không nhầm hai phiên bản.

Plans BE-*-plan.md ghi scope ở thời điểm thực hiện, không là production acceptance mới.
Đọc [backlog hiện hành](../tasks.md) và [business requirements](../business-requirements.md) trước tiếp tục.
Giữ plan cũ để audit/mapping; không xóa vì chứa quyết định triển khai chưa chắc đã được chuyển hết.
